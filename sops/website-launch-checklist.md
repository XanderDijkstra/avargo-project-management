# Lanseringssjekkliste for nettside

Før DNS pekes over og siden går live, gå gjennom denne listen.

## Teknisk

- [ ] SSL-sertifikat aktivt
- [ ] Sitemap.xml generert og lagt til i Search Console
- [ ] robots.txt på plass og korrekt
- [ ] Alle interne lenker fungerer (ingen 404)
- [ ] 404-side eksisterer og er pen
- [ ] Mobiltilpasning testet på iOS og Android
- [ ] Lighthouse-score > 85 på alle kategorier
- [ ] Favicon på plass

## Sporing

- [ ] Google Analytics 4 installert og verifisert
- [ ] Google Tag Manager container live
- [ ] Meta Pixel (hvis aktuelt) verifisert i Events Manager
- [ ] Google Ads-konverteringstag installert (hvis aktuelt)

## SEO

- [ ] Alle sider har unik title og meta description
- [ ] OG-bilder satt for sosial deling
- [ ] Strukturert data (Schema.org) på forside
- [ ] Search Console verifisert

## Innhold

- [ ] Korrekturlest av kunde
- [ ] Kontaktinfo og NAP konsistent med GBP
- [ ] Personvernerklæring og cookies på plass
